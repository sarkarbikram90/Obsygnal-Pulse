# Obsygnal-Pulse REST API Reference

## Base URL

```text
http://localhost:8080/api/v1
```

All public API endpoints adhere to [Semantic Versioning and URL Path Prefix Versioning](versioning.md).

---

## Authentication & Headers

Obsygnal-Pulse supports two authentication mechanisms:

1. **User Authentication (JWT Bearer Token)**:
   ```http
   Authorization: Bearer <jwt_access_token>
   ```
2. **Machine Telemetry Authentication (Cluster Agent API Key)**:
   ```http
   Authorization: Bearer obsygnal_sec_9f8a31b2...
   ```

### Common Request Headers:
- `Content-Type: application/json`
- `X-Request-ID: <uuid>` (Optional; autogenerated if omitted for distributed tracing)

## Endpoints

### 1. Health & Readiness Probes

#### `GET /health`
Liveness probe. Returns HTTP 200 if the server process is responsive.

**Response:**
```json
{
  "status": "healthy",
  "checks": [
    { "name": "clickhouse", "status": "healthy", "latency_ms": 2 },
    { "name": "redis", "status": "healthy", "latency_ms": 1 }
  ],
  "version": "1.0.0",
  "uptime_seconds": 1420
}
```

#### `GET /ready`
Readiness probe. Returns HTTP 200 only when all required persistent dependencies are initialized.

### 2. Multi-Tenant Authentication & Identity

#### `POST /auth/register`
Creates a new tenant user account, organization workspace, and default owner membership.

**Request Body:**
```json
{
  "email": "engineer@company.com",
  "password": "SecurePassword123!",
  "display_name": "Alex Mercer",
  "org_name": "Acme AI Labs"
}
```

**Response (HTTP 201):**
```json
{
  "user": {
    "id": "usr_94b1c8e2",
    "email": "engineer@company.com",
    "display_name": "Alex Mercer",
    "created_at": "2026-08-14T00:00:00Z"
  },
  "organization": {
    "id": "org_71a0f9d4",
    "name": "Acme AI Labs",
    "tier": "growth_pro"
  },
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

#### `POST /auth/login`
Authenticates user credentials and returns a signed JWT token containing tenant claims.

**Request Body:**
```json
{
  "email": "engineer@company.com",
  "password": "SecurePassword123!"
}
```

**Response (HTTP 200):**
```json
{
  "user": {
    "id": "usr_94b1c8e2",
    "email": "engineer@company.com",
    "display_name": "Alex Mercer"
  },
  "organization": {
    "id": "org_71a0f9d4",
    "name": "Acme AI Labs",
    "tier": "growth_pro"
  },
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

#### `GET /auth/me` *(Protected)*
Returns the current authenticated user profile, organization context, and RBAC role.

### 3. Edge Agent API Key Management

#### `POST /api-keys` *(Protected — Admin/Owner)*
Generates a new machine-to-machine secret API key for an edge cluster collector.

**Request Body:**
```json
{
  "name": "us-east-prod-h100-collector",
  "cluster_id": "cluster-h100-01"
}
```

**Response (HTTP 201):**
```json
{
  "id": "key_31b8f9e1",
  "name": "us-east-prod-h100-collector",
  "cluster_id": "cluster-h100-01",
  "key": "obsygnal_sec_9f8a31b2c4e5f6a7b8c9d0e1f2a3b4c5",
  "created_at": "2026-08-14T00:00:00Z"
}
```

#### `GET /api-keys` *(Protected)*
Lists active collector API keys for the tenant organization (secrets are masked).

### 5. Cluster Observability & Inefficiencies

#### `GET /cluster/overview` *(Protected)*
Returns aggregated cluster metrics, healthy/idle GPU count, and monthly monetary waste.

**Response (HTTP 200):**
```json
{
  "cluster_id": "cluster-h100-01",
  "total_nodes": 8,
  "healthy_nodes": 8,
  "total_gpus": 64,
  "active_gpus": 52,
  "idle_gpus": 12,
  "avg_utilization": 68.4,
  "avg_memory_usage": 61.2,
  "active_jobs": 14,
  "inefficiency_score": 24.5,
  "estimated_waste_usd": 6820.00,
  "timestamp": "2026-08-14T00:00:00Z"
}
```

#### `GET /inefficiencies` *(Protected)*
Lists active compute bottlenecks detected across the cluster.

**Query Parameters:**
- `cluster_id` (string, optional)
- `severity` (string: `low`, `medium`, `high`, `critical`)
- `type` (string: `idle_gpu`, `cpu_starvation`, `stalled_training`, `cuda_memory_fragmentation`, etc.)

### 6. Recommendations & 1-Click Auto-Remediation

#### `GET /recommendations` *(Protected)*
Returns active ROI optimization recommendations sorted by monetary savings.

**Response (HTTP 200):**
```json
[
  {
    "id": "rec_8f3a9e12",
    "cluster_id": "cluster-h100-01",
    "gpu_id": "gpu-0",
    "title": "Defragment PyTorch CUDA Memory Allocator",
    "description": "PyTorch has reserved 68GB of VRAM while utilizing only 24GB. Defragmenting recovers 44GB of VRAM.",
    "severity": "high",
    "action_type": "kubernetes_patch",
    "estimated_savings_monthly": 1752.00,
    "confidence_score": 0.94,
    "status": "pending",
    "remediation_payload": {
      "patch": "env:\n  - name: PYTORCH_CUDA_ALLOC_CONF\n    value: \"expandable_segments:True\""
    }
  }
]
```

#### `POST /recommendations/:id/apply` *(Protected)*
Triggers 1-click auto-remediation (applies Kubernetes patch or executes webhook action).

#### `POST /recommendations/:id/dismiss` *(Protected)*
Dismisses a recommendation with an optional reason.

---

### 7. Usage Metering & Audit Logging

#### `GET /billing/usage` *(Protected)*
Returns monthly GPU-hours monitored, active cluster nodes, and tier quotas.

#### `GET /audit-logs` *(Protected)*
Returns immutable SOC2 compliance audit log event history for security governance.

---

### 8. Operational Metrics

#### `GET /metrics` *(Public)*
Prometheus metrics scrape target exporting Go runtime and application operational metrics.
